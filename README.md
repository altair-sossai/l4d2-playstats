# L4D2 Play Stats

🌐 **English** | [Português](https://github.com/altair-sossai/l4d2-playstats/blob/main/README.pt.md) | [Español](https://github.com/altair-sossai/l4d2-playstats/blob/main/README.es.md)

Allows extracting existing data from statistics files generated by the *l4d2_playstats.smx* plugin.

The library targets **.NET 10** (`net10.0`) and has no package dependencies.

## Installation

```shell
dotnet add package L4D2PlayStats
```

## Enabling statistics logging on the Left 4 Dead 2 server
To enable statistics, you must have the *l4d2_playstats.smx* plugin installed on the server and add the following parameters to the configuration file:
```code
confogl_addcvar sm_stats_writestats 1
-- or
sm_cvar sm_stats_writestats 1
```
See more details at: https://github.com/SirPlease/L4D2-Competitive-Rework

How the plugin writes the files:
- Only in versus mode, to `addons/sourcemod/logs/`, one file per map, named `<yyyy-MM-dd>_<HH-mm>_<round>_<map>.txt` (for example `2023-02-04_03-13_0011_c8m1_apartment.txt`).
- The file is created at the end of the first half and appended to at the end of the second half. The `[Scoring:]` and `[PlayerNames:]` sections are only written after the second half, so a file read after the first half has no scoring and no player names.
- `sm_stats_writestats 2` also appends human-readable tables to the same file. The library is tested with files written with `1`.

To send these files to [l4d2-playstats-api](https://github.com/altair-sossai/l4d2-playstats-api), use the [l4d2_playstats_sync](https://github.com/altair-sossai/l4d2-zone-server/blob/master/addons/sourcemod/plugins/optional/l4d2_playstats_sync.smx) plugin.

## How to use
Pass the content of a statistics file to the `Statistics` constructor, or use `Statistics.TryParse`, which returns `false` instead of throwing when the content is empty or invalid.

```csharp
using L4D2PlayStats;

var content = File.ReadAllText("2023-02-04_03-13_0011_c8m1_apartment.txt");

if (!Statistics.TryParse(content, out var statistics) || statistics == null)
{
    Console.WriteLine("Not a valid statistics file.");
    return;
}

var gameRound = statistics.GameRound;
Console.WriteLine($"{gameRound?.MapName} - {gameRound?.ConfigurationName} - {statistics.MapElapsed}");

foreach (var half in statistics.Halves)
{
    Console.WriteLine($"Team {half.RoundHalf?.Team}: SI killed {half.RoundHalf?.SiKilled}, MVP (SI damage) {half.MvpSiDamage?.PlayerName}");

    foreach (var player in half.Players)
    {
        Console.WriteLine($"  {player.PlayerName} {player.ProfileUrl}: SI damage {player.SiDamage}, common {player.Common}, FF given {player.FfGiven}");
    }

    foreach (var infected in half.InfectedPlayers)
    {
        Console.WriteLine($"  {infected.PlayerName}: damage {infected.DmgTotal}, spawns {infected.Spawns}");
    }
}

if (statistics.Scoring is { } scoring)
{
    Console.WriteLine($"A {scoring.TeamA?.Score} x {scoring.TeamB?.Score} B");
}
```

### Main types

| Type | What it holds |
|------|---------------|
| `Statistics` | `GameRound`, `Halves`, `Scoring`, `PlayerNames`, `TeamA` / `TeamB` (names of the survivors of each team), `MapStart`, `MapEnd`, `MapElapsed`. `ToString()` writes the content back in the plugin's file format. |
| `GameRound` | `Round`, `When`, `TeamSize`, `ConfigurationName`, `MapName`. |
| `Statistics.Half` | `RoundHalf`, `Progress`, `Players`, `InfectedPlayers`, plus `MvpSiDamage`, `MvpCommon`, `LvpFfGiven` and the ordered sequences `MvpsSiDamage`, `MvpsCommon`, `LvpsFfGiven`. |
| `RoundHalf` | Team totals for the half: `Team`, `Restarts`, `PillsUsed`, `KitsUsed`, `DefibsUsed`, `Common`, `SiKilled`, `SiDamage`, `SiSpawned`, `WitchKilled`, `TankKilled`, `Incaps`, `Deaths`, `FfDamageTotal`, start/end/pause/tank times and `RoundElapsed`, `PauseElapsed`, `TankElapsed`. |
| `Progress` | `Team`, `Survived`, `MaxCompletionScore`, `MaxFlowDist` and the list of `Flows` (`FarFlowDist`, `CurFlowDist`). |
| `Player` | One survivor in a half: shots, hits and headshots per weapon class, `Common`, `SiKilled`, `SiDamage`, skeets, levels, crowns, `DmgTaken`, friendly fire given/taken (totals and by type), `TankDamage`, `WitchDamage`, present/alive/upright times. |
| `InfectedPlayer` | One infected player in a half: damage (`DmgTotal`, `DmgUpright`, `DmgTank`, ...), `HunterDPs`, `JockeyDPs`, `DeathCharges`, `Booms`, `Ledged`, spawns per class, `TankPasses`, present times. |
| `Scoring` | `TeamA` / `TeamB` (`Letter`, `FirstScoresSet`, `Score`), `ScoreDiff`, `Draw`, `TeamAWon`, `TeamBWon`. |
| `PlayerName` | `Index`, `SteamId`, `Name`. |

`Player`, `InfectedPlayer` and `PlayerName` expose `SteamId` (as written by the plugin, e.g. `STEAM_1:0:15152893`) and the derived `CommunityId` (SteamID64), `Steam3` and `ProfileUrl`. `PlayerName` on `Player` / `InfectedPlayer` is filled from the `[PlayerNames:]` section, so it is `null` while that section is missing.

`RoundHalf`, `Player` and `InfectedPlayer` also have an indexer by the `RoundStats`, `PlayerStats` and `InfectedStats` enums (namespace `L4D2PlayStats.Enums`) that returns each value as `long` (times as Unix seconds); the `DataType()` extension methods in `L4D2PlayStats.Extensions` tell whether a field is a number or a date.

Times read from Unix timestamps (`StartTime`, `MapStart`, `TimeStartPresent`, ...) are UTC `DateTime` values. `GameRound.When` is the server's local date and time as written in the file.

## Building and testing
Requires the .NET 10 SDK.

```shell
git clone https://github.com/altair-sossai/l4d2-playstats.git
cd l4d2-playstats
dotnet build
dotnet test
```

The tests (MSTest) are in `L4D2PlayStats.UnitTest`. `StatisticsTests` parses the sample file in `L4D2PlayStats.UnitTest/Statistics` and checks that `ToString()` reproduces it line by line.

## Publishing
`azure-pipelines.yml` runs on every push to `main`: it builds, runs the tests, packs the library using the build number as the package version (`1.0.0.<revision>`, which overrides the `<Version>` in the csproj) and publishes the `.nupkg` as the `package` build artifact. Pushing that artifact to nuget.org is not done by this file.

To create and push a package yourself:

```shell
dotnet pack L4D2PlayStats/L4D2PlayStats.csproj -c Release -o ./artifacts -p:PackageVersion=1.0.0-local
dotnet nuget push ./artifacts/L4D2PlayStats.1.0.0-local.nupkg --source https://api.nuget.org/v3/index.json --api-key <your-api-key>
```

The `L4D2PlayStats` package id on nuget.org is owned by this project, so to publish a fork change `<PackageId>` in `L4D2PlayStats/L4D2PlayStats.csproj`, or push to your own feed. The package includes this README and `assets/icon.png`.
